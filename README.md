AI chatbot using Python.

## Features

- 

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python bot.py
```

## Commands
| Command | Function |
|---|---|
| /start | Start bot |
| /help | Show help |
| /ai | AI chat |
| /image | Send image |
